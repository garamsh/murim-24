# Murim24

A 2D martial-arts RPG for PC and mobile, set inside a living world simulation. Factions, villages and wars change with or without the player. The player is one creature in that world, and on death is reborn as someone else in the same world. Murim24 is a working title.

## Documents

- `docs/concept.md` — the game concept
- `docs/art-direction.md` — how the game looks
- `docs/architecture/README.md` — how the system is shaped and why
- `AGENTS.md` — how to contribute

## Run

Requires Godot 4.7. Open `project.godot` in the editor, or run `godot --path .` from the repository root.

## Check

`make ci` runs every check the project has.
